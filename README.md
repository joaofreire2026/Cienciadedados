## 📌 Sobre o Repositório

> *"Sem dados, você é apenas mais uma pessoa com uma opinião."* — W. Edwards Deming

Este repositório reúne projetos, estudos e experimentos em **Ciência de Dados**, desenvolvidos com foco em aprendizado contínuo e aplicação prática. Cada projeto representa uma jornada de investigação: da pergunta bruta ao insight acionável.

O objetivo não é apenas escrever código — é **aprender a pensar com dados**, desenvolver intuição analítica e construir soluções que resolvem problemas reais.
